## 通用Definition of Done
代码diff归属清晰；旧数据保护；无密钥泄露；typecheck/unit/build/Mock E2E通过；截图与真实人工操作通过；能力账本注明已实现/原型/规划/待验证；有失败/回滚处理。真实收费调用必须另有用户启动/授权，本轮授权仅设计基线提交推送；生产开发、部署与真实调用不在本轮范围内。
