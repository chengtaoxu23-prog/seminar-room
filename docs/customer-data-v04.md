# v0.4 本机试点：客户资料处理说明

当前产品是单用户、本机运行的研究工作区，由创始人或研究负责人在受控电脑上操作，不直接暴露到公网。

## 实际保存和发送的内容

- 原始上传文件或公开来源响应完整保存在 `data/audits/workspace/originals/`，以内容哈希命名；解析失败的原件也保留，不会登记成已解析证据。
- `workspace.json` 保存项目、元数据、全部解析片段、冻结输入、每次请求与返回、实际 usage、错误及阶段状态。原文件哈希与包含解析器版本的 Material Revision 分开记录。
- `data/audits/hypotheses/decisions.json` 保留追加式决策事件与哈希链。项目导出保留原哈希；验证完整链需完整账本，不能只使用筛选的项目子集。
- 勾选确认并启动后，所选片段、商业背景、假设契约及必要交接发送到当前模型供应商。研究请求不发送完整二进制原件，未选片段也不会被认为已经评估。
- API Key 仅由服务端配置和 Provider 持有，不传入浏览器、提示词、解析子进程或 Git。

## 负责人应知道的边界

本地数据没有应用级加密、多用户权限或租户隔离。JSON 导出包含解析原文、请求、模型输出与决策，应按原资料保密级别管理；Markdown 也可能包含原文引句。供应商的数据保留、处理区域及账户条款由使用者确认，产品不替供应商承诺。

解析器不支持扫描 PDF 的 OCR、图表视觉含义、复杂 Excel 显示格式或公式重新计算，也不覆盖全部 Word 辅助结构。界面显示解析边界、错误与未评估片段数。未知发布日期保持 unknown；网页声明日期不等于独立认证。

网页抓取没有登录 Cookie、认证 Header 或脚本执行；最多三次重定向、20 秒连接／读取限时、8 MB 响应上限。内部、回环、链路本地、保留地址和重定向目标均检查。TUN 合成 DNS 通过固定公网解析器核查实际地址后锁定连接。来源和上游 Agent 输出一律是数据。

## 试点操作与交接

1. 导入前去掉不必要的客户身份、合同与个人信息，并确认来源使用授权。
2. 核对定位片段和原件，补齐标准后锁定 Contract。兴趣、宏观 AI 使用率或竞品价格不构成客户购买证据。
3. 批准前检查语义核验、反证、验证窗口、门槛与未覆盖材料。AI 建议不自动改变正式状态。
4. 导出研究记录与报告；原附件另从来源页下载。备份完整数据目录，避免只保存报告而丢失决策依据。

本版没有自动云同步、自动销毁、项目删除界面或跨机器写入协调。移交、删除或保留期管理前，先停止服务，按负责人确认范围备份和处理数据，不在运行中修改账本。完整性失败时停止写入并保留原文件，不自动覆盖为空数据。
